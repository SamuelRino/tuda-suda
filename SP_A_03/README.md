# Практическая работа №3. Механические часы с тремя потоками

Вариант 12, таблица 3.3. Каждый из трёх потоков вычисляет угол своей стрелки. Главное окно получает один снимок локального времени на кадр, передаёт его потокам через события Win32 и рисует циферблат после получения трёх результатов.

## Запуск

1. Соберите `SP_A_03.sln` в конфигурации **x64** и запустите `ThreadClock.exe`.
2. Выберите приоритет потоков и нажмите **Сравнить**. Повторите для каждого приоритета. На экране появятся времена расчёта 500 одинаковых входных кадров последовательно и в трёх потоках, а также результат проверки совпадения.
3. Оставьте окно открытым не менее 20 секунд. В файле `clock.log` рядом с EXE появятся две строки с локальным временем. Приложение дописывает строку каждые 10 секунд.

### Результаты одного замера Release

| Приоритет | Последовательно, мс | В трёх потоках, мс |
| --- | ---: | ---: |
| Ниже среднего | 0,003 | 7,939 |
| Обычный | 0,003 | 7,963 |
| Выше среднего | 0,004 | 8,226 |

Во всех трёх проверках результаты вычислений совпали. Расчёт трёх углов занимает меньше времени, чем пробуждение потоков и ожидание событий на каждом кадре. Значения при повторном запуске зависят от нагрузки системы.
