# Практическая работа №5. Локальная память, DLL и буфер обмена

Вариант 12, таблица 5.2. `MemoryDemo.exe` использует функции из `MemoryBlock.dll` через библиотеку импорта. DLL выделяет перемещаемый блок через `LocalAlloc`, предоставляет доступ через `LocalLock` и `LocalUnlock`, читает, записывает, копирует текст и освобождает блок через `LocalFree`.

## Запуск

1. Соберите `SP_A_16.sln` для **x64**. Запустите `MemoryDemo.exe` из каталога сборки вместе с `MemoryBlock.dll`.
2. Выберите блок **A**, нажмите **Выделить**, **Заблокировать**, введите текст и нажмите **Записать**.
3. Выберите блок **B**, выделите и заблокируйте его. Нажмите **Скопировать A → B**, измените текст в редакторе и нажмите **Прочитать**. В редактор вернётся содержимое блока.
4. Для проверки буфера нажмите **В буфер обмена**, измените текст в редакторе, затем нажмите **Из буфера обмена**.
5. По очереди выберите каждый блок, нажмите **Разблокировать** и **Освободить**.

Обмен с другими приложениями идёт в формате `CF_UNICODETEXT`. Для передачи текста Windows требуется переносимый дескриптор `GlobalAlloc`, который приложение передаёт системе через `SetClipboardData`. Рабочие блоки A и B выделяются в локальной памяти.
