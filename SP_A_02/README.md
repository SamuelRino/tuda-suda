# Практическая работа №2. Диспетчер задач

Вариант 12, таблица 2.1. Диспетчер показывает все процессы из снимка системы, позволяет принудительно завершить выбранный процесс и запускать исполняемые файлы в трёх экземплярах. При внешнем запуске исходный экземпляр уже существует, поэтому диспетчер запускает ещё два.

## Запуск

1. Соберите `SP_A_02.sln` в конфигурации **x64** и запустите `ProcessManager.exe`.
2. Укажите путь к тестовой программе, поддерживающей несколько экземпляров, и нажмите **Запустить ×3**. В списке появятся три PID. Для завершения выберите один PID, нажмите соответствующую кнопку и подтвердите.
3. Укажите папку с тестовой программой и включите наблюдение. Запустите программу вручную вне диспетчера. В списке появятся исходный PID и два дополнительных. Пустое поле включает наблюдение по текущему сеансу Windows после подтверждения.

`CreateToolhelp32Snapshot` обновляет список каждые 250 мс. При включении наблюдения текущий снимок становится начальным. Для найденного внешнего процесса диспетчер узнаёт путь через `QueryFullProcessImageNameW` и передаёт его в `CreateProcessW`. Экземпляры, созданные диспетчером, и обнаруженные потомки этих экземпляров исключаются из повторного запуска.

Копии запускаются с параметрами по умолчанию для EXE. Наблюдение охватывает процессы текущего сеанса, путь к которым доступен, а очень короткий процесс может целиком выполниться между снимками. Системные ограничения доступа действуют и для завершения процессов.
