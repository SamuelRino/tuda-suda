# Практическая работа №1. Управление Windows-приложениями

Вариант 12, таблица 1.1. Цель работы — передать состояние флажка в другое приложение и отобразить рисунок в соответствии с этим состоянием.

## Запуск

1. Откройте `SP_A_01.sln` в Visual Studio 2022, выберите **x64** и соберите решение.
2. Запустите `PictureViewer.exe`, затем `PictureController.exe` из папки `bin\x64\Debug` или `bin\x64\Release`.
3. Нажмите **Нарисовать**. Если флажок снят, солнце будет справа. Установите флажок и нажмите кнопку снова. В зеркальном варианте солнце появится слева.

Контроллер находит окно по имени класса через `FindWindowW` и передаёт состояние флажка зарегистрированным сообщением. Окно просмотра сохраняет состояние и рисует через GDI в обработчике `WM_PAINT`. Для зеркального изображения используется `StretchBlt` с отрицательной шириной области назначения.
