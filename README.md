# tuda-suda

## Практические работы по системному программированию

Вариант **12**. Для каждой работы есть отдельное решение Visual Studio 2022. Для сборки нужен компонент **«Разработка классических приложений на C++»** с MSVC v143 и Windows SDK.

| Работа | Тема | Решение |
| --- | --- | --- |
| [№1](SP_A_01/) | Управление другим приложением и зеркальное отражение рисунка | [SP_A_01.sln](SP_A_01/SP_A_01.sln) |
| [№2](SP_A_02/) | Диспетчер задач и тройной запуск процессов | [SP_A_02.sln](SP_A_02/SP_A_02.sln) |
| [№3](SP_A_03/) | Механические часы с тремя потоками | [SP_A_03.sln](SP_A_03/SP_A_03.sln) |
| [№4](SP_A_04/) | Синхронизация процессов в модели магазина | [SP_A_04.sln](SP_A_04/SP_A_04.sln) |
| [№5](SP_A_05/) | Локальная память, DLL и текстовый буфер обмена | [SP_A_05.sln](SP_A_05/SP_A_05.sln) |
| [№6](SP_A_06/) | Вызов `GetDiskFreeSpaceA` на C и MASM | [SP_A_06.sln](SP_A_06/SP_A_06.sln) |

Работы №1–5 собираются для **x64**, работа №6 — для **Win32 (x86)**. В каждой папке есть порядок запуска. Для №6 также приложены отчёт и два готовых EXE.
