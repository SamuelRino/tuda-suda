# tuda-suda

## Практические работы по системному программированию

Вариант **12**. Для каждой работы есть отдельное решение Visual Studio 2022. Для сборки нужен компонент **«Разработка классических приложений на C++»** с MSVC v143 и Windows SDK.

| Работа | Тема | Решение |
| --- | --- | --- |
| [№1](SP_A_12/) | Управление другим приложением и зеркальное отражение рисунка | [SP_A_12.sln](SP_A_12/SP_A_12.sln) |
| [№2](SP_A_13/) | Диспетчер задач и тройной запуск процессов | [SP_A_13.sln](SP_A_13/SP_A_13.sln) |
| [№3](SP_A_14/) | Механические часы с тремя потоками | [SP_A_14.sln](SP_A_14/SP_A_14.sln) |
| [№4](SP_A_15/) | Синхронизация процессов в модели магазина | [SP_A_15.sln](SP_A_15/SP_A_15.sln) |
| [№5](SP_A_16/) | Локальная память, DLL и текстовый буфер обмена | [SP_A_16.sln](SP_A_16/SP_A_16.sln) |
| [№6](SP_A_17/) | Вызов `GetDiskFreeSpaceA` на C и MASM | [SP_A_17.sln](SP_A_17/SP_A_17.sln) |

Работы №1–5 собираются для **x64**, работа №6 — для **Win32 (x86)**. В каждой папке есть порядок запуска. Для №6 также приложены отчёт и два готовых EXE.
