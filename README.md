# tuda-suda

## Практические работы по системному программированию

Вариант **12**. Для каждой работы есть отдельное решение Visual Studio 2022. Для сборки нужен компонент **«Разработка классических приложений на C++»** с MSVC v143 и Windows SDK.

| Работа | Тема | Решение |
| --- | --- | --- |
| [№1](Practice01/) | Управление другим приложением и зеркальное отражение рисунка | [Practice01.sln](Practice01/Practice01.sln) |
| [№2](Practice02/) | Диспетчер задач и тройной запуск процессов | [Practice02.sln](Practice02/Practice02.sln) |
| [№3](Practice03/) | Механические часы с тремя потоками | [Practice03.sln](Practice03/Practice03.sln) |
| [№4](Practice04/) | Синхронизация процессов в модели магазина | [Practice04.sln](Practice04/Practice04.sln) |
| [№5](Practice05/) | Локальная память, DLL и текстовый буфер обмена | [Practice05.sln](Practice05/Practice05.sln) |
| [№6](Practice06/) | Вызов `GetDiskFreeSpaceA` на C и MASM | [Practice06.sln](Practice06/Practice06.sln) |

Работы №1–5 собираются для **x64**, работа №6 — для **Win32 (x86)**. В каждой папке есть порядок запуска. Для №6 также приложены отчёт и два готовых EXE.
